Kinetic 🏋️‍♂️

Kinetic es una aplicación móvil moderna desarrollada con React Native y Expo, diseñada específicamente para optimizar la gestión de entrenamientos y el seguimiento de progreso en el gimnasio.

Este proyecto utiliza EAS (Expo Application Services) para un flujo de trabajo de integración y despliegue continuo (CI/CD), permitiendo generar compilaciones nativas de alta eficiencia.

🚀 Características Principales 

-Gestión de Rutinas: Creación y seguimiento de entrenamientos personalizados.

Interfaz Intuitiva: Diseño enfocado en la experiencia del usuario (UX) durante el ejercicio intenso.
-Compilación Multiplataforma: Optimizada para Android e iOS mediante el ecosistema Expo.

-Seguimiento de Progreso: Visualización de métricas de rendimiento físico.

🛠️ Tecnologías Utilizadas

-Framework: React Native

-Entorno: Expo (SDK 50+)

-Lenguaje: JavaScript / TypeScript

-Servicios de Build: EAS (Expo Application Services)

-Gestión de Estado: (Opcional: Redux / Context API)
